# 💖 Love Page

Um projeto especial e feito com carinho para a minha namorada.  
Essa página foi desenvolvida com **HTML**, **CSS** e **JavaScript**.

## ✨ Sobre o projeto

A **Love Page** é uma página personalizada com:

- 💌 Uma cartinha especial escrita por mim.
- 🎶 Links de músicas que marcaram nosso relacionamento.
- 💕 Efeitos visuais de corações flutuando ao fundo com nossas fotos.
